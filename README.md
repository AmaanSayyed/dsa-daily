# DSA Daily 🚀

This repository documents my daily practice of **Data Structures & Algorithms**.

The goal is simple:
> **Solve at least one DSA problem regularly and stay consistent.**

This is not about solving the hardest problems.
This is about showing up every day and improving step by step.

---

## 🧠 Why this repo?

- Build strong problem-solving fundamentals
- Stay consistent with daily practice
- Track progress publicly for accountability
- Prepare for technical interviews
- Improve logical thinking alongside real-world development

---

## 🗂️ Repository Structure

Problems are organized by topic:

```

dsa-daily/
├── arrays/
├── strings/
├── linked-list/
├── stack-queue/
├── recursion/
├── trees/
├── graphs/
├── dp/
└── README.md

```

Each solution includes:
- Problem description
- Approach used
- Time & space complexity
- Clean and readable code
